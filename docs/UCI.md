# UCI integration

The engine can be launched in protocol mode with:

```bash
./build/chess_engine --uci
```

UCI is intended for communication with chess GUIs and uses coordinate move notation, not SAN. For example, `e2e4` represents the same move as `e4` in the terminal interface.

A minimal manual handshake/search sequence is:

```text
uci
isready
position startpos
go depth 3
quit
```

Use the executable path generated by your local CMake configuration when adding the engine to a GUI.
